CPJ - Cyber Programming Language

Complete CPJ Programming Language Guide

CPJ is a multi-target programming language and standalone web engineering language. A single `.cpj` source can generate Python, Java GUI code, browser HTML/CSS/JavaScript, dependency-free servers, APIs, SQLite stores, CPJPress CMS projects, and Windows-native tooling.

Installation

Install CPJ On Windows

CPJ installs as a native Windows command. The installer copies the compiler, runtime tools, standard library, docs, and samples into `%LOCALAPPDATA%\CPJ` and adds the `bin` folder to the user PATH.

Standalone installer
powershell -ExecutionPolicy Bypass -File D:\CPJ\CPJ\dist\CPJ-Setup-Windows.ps1
CPJ
CPJ --help
Build and install from source
powershell -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\install_windows.ps1
cpj --web-only -o generated samples\web_app.cpj

Bare `CPJ` now prints readiness and usage. It does not try to compile a default sample into `C:\Windows\System32`.

Command Line

Compiler CLI

The `cpj` command compiles `.cpj` files into generated backends. For web work, `--web-only` emits a static HTML file plus a full standalone server project.

CommandPurpose
cpj --helpShow usage and runtime root.
cpj source.cpjEmit Python and standalone web output.
cpj --web-only -o generated source.cpjEmit only the web target and do not run Python.
cpj --no-web --no-run source.cpjEmit Python backend without generated web artifacts.
cpj -v source.cpjShow generated subprocess commands.
Language Basics

CPJ Source Structure

A CPJ file is a sequence of declarations, statements, and domain blocks. The compiler recognizes core language constructs plus specialized `GUI` and `web` blocks.

CommentsUse `#` or `//` lines in web blocks. Ordinary language files follow the parser rules of the active frontend.
StatementsAssignments, function calls, prints, returns, loops, conditionals, imports, and exceptions are supported by the Python emitter.
BlocksCurly braces group classes, functions, routes, sections, templates, stores, uploads, and CMS configuration.
TargetsOne source can feed Python runtime code, Java GUI generation, C++ compiler support, and standalone browser/server output.
Hello CPJ
class HelloWorld {
    def main() {
        print("Hello, CPJ World!")
    }
}

def add(a: int, b: int) -> int {
    return a + b
}
Types

Types And Data Shapes

CPJ supports primitive annotations, user-defined `struct` and `class` declarations, GUI coercion maps, web models, and SQLite store field types.

Primitive`int`, `float`, `double`, `bool`, `boolean`, `str`, `string`, `text`, `email`, `blob`.
User-defined`struct Point { x: int y: int }` and `class Person { ... }`.
Web model`model Contact { field email email required }` emits design metadata.
Store field`store Lead { field email text required }` creates SQLite-backed API columns.
Struct, class, model, store
struct Point {
    x: int
    y: int
}

class Person {
    name: string
    age: int

    def greet(self) {
        print("Hello, " + self.name)
    }
}

web {
    model Contact {
        field name string required
        field email email required
    }

    store Lead {
        field name text required
        field email text required
    }
}
Functions

Functions And Modules

Functions use `def`, optional type annotations, and `return`. The Python emitter supports calls, returns, imports, lambdas, comprehensions, attributes, subscript access, and common expression operators.

Function example
import math

def area(radius: float) -> float {
    return 3.14159 * radius * radius
}

def main() {
    print(area(4.0))
}
Objects

Classes And Structs

Use `struct` for simple field containers and `class` for fields plus methods. CPJ maps these constructs across the available backends where supported.

Object-oriented CPJ
class Counter {
    value: int

    def inc(self) {
        self.value = self.value + 1
        return self.value
    }
}
Flow

Control Flow And Expressions

CPJ supports familiar imperative flow: `if`, `while`, `for`, boolean expressions, binary operators, lists, dictionaries, comparisons, and comprehensions through the Python-oriented emitter path.

Control flow
def score(items) {
    total = 0
    for item in items {
        if item > 0 {
            total = total + item
        }
    }
    return total
}
Errors

Error Handling And Diagnostics

CPJ supports `try`, exception handlers, `raise`, and generated diagnostics in the web target. Web diagnostics report SEO, accessibility, and security warnings.

Exception shape
try {
    result = risky_call()
} except Error as err {
    print(err)
}
GUI

Desktop GUI Blocks

The `GUI` block generates Java Swing-oriented interfaces. Widget type annotations help the runtime coerce form data before handler calls.

GUI block
GUI {
    types {"count":"int", "flag":"bool"}
    addTextField("count")
    addCheckbox("flag")
    addButton("Go", handler(count, flag))
    show()
}
Standalone Web

Web Engineering In CPJ

The `web` block is CPJ's standalone web engineering surface. It emits a static `index.html`, embedded browser runtime, generated `server.py`, OpenAPI, PWA files, design tokens, component inventory, diagnostics, SQLite stores, upload handlers, and routes.

Complete web block
web {
    title "CPJ Web Engineering"
    meta description "A standalone CPJ web application."
    pwa "CPJ Web Engineering"
    theme primary "#2457c5"
    server port 8080

    middleware security {
        header "X-Content-Type-Options" "nosniff"
        cors "*"
        request-id true
    }

    guard upload_token {
        path "/api/uploads/media"
        token "dev-token"
    }

    component stack_badge {
        badge "HTML5 + CSS + JS + API"
    }

    api "/api/health" {
        json status "ok"
        json cpj true
    }

    store Lead {
        field name text required
        field email text required
        seed name "Ada" email "ada@example.com"
    }

    upload media {
        path "/api/uploads/media"
        dir "uploads/media"
        accept "text/plain"
        max-bytes 2048
    }

    route "/dashboard" {
        h1 "CPJ server route"
        p "Rendered by the generated dependency-free CPJ server."
    }

    hero {
        use stack_badge
        h1 "Build browser apps in CPJ"
        button "Open Dashboard" -> "/dashboard"
    }
}
HTML5Sections, heroes, headings, paragraphs, images, buttons, forms, inputs, lists, and navigation.
CSSTheme tokens, responsive layouts, cards, grids, custom CSS, container queries, and animations.
JavaScriptEmbedded `window.CPJ`, state, events, counters, fetch forms, custom JavaScript, and PWA registration.
ServerRoutes, JSON APIs, POST/PUT/PATCH/DELETE parsing, uploads, guards, stores, and OpenAPI.

CMS

CPJPress

CPJPress is CPJ's WordPress-style CMS baseline. It is not a PHP WordPress clone; it is a CPJ-native CMS generated from a `.cpj` file.

CPJPress source
web {
    title "CPJPress"
    server port 8090
    pwa "CPJPress"

    cms CPJPress {
        site "CPJPress"
        blog "/blog"
        admin "/admin"
        storage "cpjpress_content.json"
        user admin admin admin "Administrator"
        plugin seo "SEO Helper" "Adds metadata hooks."
        post "hello-cpjpress" "Hello CPJPress" "This is a CPJ CMS post."
        page "about" "About CPJPress" "A CPJ-native CMS baseline."
        comment "hello-cpjpress" "First Reader" "Generated from CPJ."
    }

    hero {
        h1 "WordPress-style publishing in CPJ"
        button "View Posts" -> "/blog"
        button "Open Admin" -> "/admin"
    }
}
ContentPosts, pages, categories, comments, media metadata, and seeded content.
AdminLogin, sessions, admin publishing, media records, and seeded users.
APIs/api/posts, /api/comments, /api/media, /api/plugins, OpenAPI, RSS, and sitemap.
RuntimeDependency-free Python standard-library server with CPJ stores, middleware, services, and marketplace metadata.

Architecture

How CPJ Fits Together

The C++ compiler front door invokes Python emitters for backend and web targets. The web emitter produces browser and server artifacts; CPJPress adds a CMS runtime.

Architecture Layers

  • cpj.exeNative Windows command and compiler entry point.
  • tools/Python parser, emitter, web emitter, package helpers, and CPJPress runtime.
  • stdlib/CPJ standard library modules.
  • samples/Reference CPJ programs and web/CMS examples.
  • dist/Windows package and standalone installer.

CPJ Cheat Sheet

This quick reference summarizes the language-level blocks used in modern CPJ projects.

SyntaxMeaning
class Name { ... }Declare class fields and methods.
struct Name { ... }Declare a simple data structure.
def name(args) { ... }Declare a function.
GUI { ... }Generate desktop GUI runtime behavior.
web { ... }Generate standalone HTML5/web/server artifacts.
component name { ... }Define reusable web markup.
template name { slot content }Define a route layout with content insertion.

api "/path" { json key value }Define method-aware JSON API.
store Name { field ... }Define SQLite-backed CRUD API.
migration name { ... }Add store fields and indexes.
upload name { ... }Define multipart binary upload endpoint.
middleware name { ... }Define response headers, CORS, logging, request ID, and header checks.
pipeline name { use ... }Compose middleware into a runtime pipeline.
guard name { path ... token ... }Protect paths with bearer or `X-CPJ-Token` tokens.
service name { ... }Declare dependency-injected runtime values.
bundle name { ... }Emit browser bundle and TypeScript declaration artifacts.
marketplace name { ... }Declare plugin registry and HTML hooks.
